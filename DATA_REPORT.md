## 4. Расхождения и решения (важно для студии)

1. **Адрес.** Карточка 2ГИС (актуальная на 17.10.2026) и два свежих поста: «шоссе Коргалжын, 13Б, офис 511, 5 этаж». Более старые источники упоминают «ул. Анет баба 6/1, офис 350», «Коргальжинское шоссе 13Б, кабинет 400» и «пр. К. Мухамедханова, 9». **Принят адрес из 2ГИС** как основной; на сайте рядом с адресом стоит ссылка на карточку, чтобы гость всегда видел актуальные данные.
2. **Дубликат.** «Двухкомнатная квартира в ЖК Only Moon» встречается в 2ГИС дважды — 76 м² и 77 м². Это два разных объекта (разные площади), оба сохранены.
3. **Название «Yesterday Coffee & Brunch»** для одного из объектов Instagram: подпись поста не называет объект, название взято с вывески на самой визуализации. Помечено в `_sources`.
4. **PABLO Aura.** В подписи сказано, что реализация идёт; изображение классифицировано как **визуализация** (не выдаём рендер за фото построенного объекта).
5. **Athletic City.** Визуализация гостиной; реализация проекта — 2021 год (слова студии). На сайте изображение помечено «визуализация», а год — как «реализация 2021».
6. **Площадки 2ГИС и Instagram пересекаются** по двум объектам (офис «Прогресс», København) — в каталоге каждый показан один раз.

## 5. Изображения: что опубликовано, а что сознательно исключено

Все изображения на сайте имеют подпись «визуализация» или «реализация». Визуализации вырезаны из проектных листов 2ГИС (сами листы на сайте не публикуются). Все кадры несут небольшой водяной знак 2ГИС; у визуализации København — логотип студии.

Исключено (список с причинами — в `scripts/optimize-images.ts`, файлы остаются в `scrape/raw/img/`):

- **обложка печатного альбома** — на развороте видны телефоны студии (кадр использован только как источник фирменного стиля и слогана);
- **групповые фото сотрудников и портрет за рабочим столом** — персональные кадры на концепте не публикуем;
- **кадр с людьми в салоне** (выбор электроустановочных изделий) — люди не давали согласия на публикацию;
- **фото посетителя со стендом светильников** — права на кадр у автора, для рассказа о процессе не нужен;
- **дубли по смыслу** (второй план, второй подбор материалов) — оставлены более информативные кадры.

Проверка: `npm run validate` не пропускает сборку, если изображение не найдено в манифесте или на диске, если у него нет blur-заглушки или если в коде появится лишняя ссылка на несуществующий файл.

## 6. Приватность

- Телефон и e-mail **не публикуются** ни в `business.json`, ни в коде: все действия ведут в WhatsApp-чат (ссылка `wa.me` из карточки 2ГИС и био Instagram), в Instagram или на карточку 2ГИС. Скрипт валидации блокирует сборку, если в коде появится похожий на номер телефона или e-mail фрагмент.
- Цитаты отзывов приведены **без имён** и без деталей заказов; из подборки исключён отзыв, где названо имя дизайнера.
- Персональные данные из брифа никуда не сохраняются: сайт формирует сообщение и открывает чат WhatsApp. Опциональный серверный релей (Telegram) по умолчанию выключен.

## 7. Артефакты

| Путь | Что это |
| --- | --- |
| `content/business.json` | единственный источник правды для сайта; валидируется Zod-схемой `lib/schema.ts` |
| `content/images.json` | манифест 60 изображений: размеры, blur-заглушка, доминирующий цвет, тип кадра |
| `scrape/raw/market-sheets-src/` | 25 проектных листов 2ГИС (1800×1800), как опубликованы |
| `scrape/raw/market-tiles/` | 50 вырезанных визуализаций (по 2 с листа) |
| `scrape/raw/text-sheets/` | контактные листы с распознанным текстом (площадь, стиль, «Особенности проекта») |
| `scrape/raw/ig-captions.json` | подписи постов Instagram дословно |
| `scrape/raw/market.json`, `scrape/raw/reviews_clean.json` | сырые данные 2ГИС: товары/услуги и отзывы |
| `scripts/optimize-images.ts` | конвейер изображений + список исключений с причинами |
| `scripts/validate-business.ts` | сборка-гейт: источники, изображения, запрещённые формулировки, приватность |
| `npm run images` / `npm run validate` / `npm run build` | пересобрать изображения / проверить данные / собрать сайт |

## 8. Что стоит перепроверить самой студии

1. Актуальность адреса и графика (мы взяли 2ГИС на 17.10.2026).
2. Состав услуг и порядок их описания на сайте.
3. Формулировки FAQ — особенно ответ про «Экспресс»-тариф: он написан по публикации о бутике EVA, а не по прайсу.
4. Слоган и палитра — взяты с фирменного бланка; если есть официальная версия логотипа, подставим её.
